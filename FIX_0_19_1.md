# 0.19.1 Türkçe sesli okuma düzeltmesi

Ücretsiz dinleme başlarken kulaklık kapalıysa okuma önceki sürümde sessizce kapatılıyordu. Artık sesli/kulaklık veya yalnızca yazılı seçenekleri açıklamalı bir iletişim kutusunda gösterilir. Dinleme sırasında otomatik okumayı açmak da aynı seçimi gösterir. Gerçek kulaklık kullanın; seçim donanımı otomatik kontrol etmez.

Türkçe sesi dene düğmesi oturumu durdurur ve yerel Türkçe TTS örneğini okur. Türkçe ses hazır değilse Android ses verisi kurulumu yönlendirmesini gösterir. Yükledikten sonra tekrar düğmeye basın. Eski/kullanılamayan ses seçimi yerine uygun dilde kullanılabilir sese geri dönülür. Ücretsiz modda profesyonel Cloud ayarının varlığı TTS hazır kontrolünü atlayamaz.

Kurulum: klasör içeriğini mevcut depo köküne kopyalayın; app/libs AAR dahil. git add . / git commit -m "Fix Turkish speech output in free listening mode" / git push. Actions yeşil olunca APK'yi yükleyin.

Test: önce Türkçe sesi dene, ardından kulaklık takıp ücretsiz Dinle modunu ve otomatik okumayı açın. Seçimde Kulaklıkla sesli çeviri seçin. Tamamlanan İngilizce bölümlerin Türkçe okunmasını kontrol edin. Yazılı ara sonuçlar kesinleşmeden seslendirilmez. Cihazın Türkçe TTS desteği gerekir; motor ve ses paketi yoksa uygulama kendi başına ses üretemez. Bu sürüm yeni duygulu ses modeli eklemez.

Yerel doğrulama: 33 Python testi, native AAR kontrolü ve XML/string referans kontrolleri geçti. Android derleme ve cihaz testi yerelde yapılmadı. versionCode 28. Kamera, ücretsiz tanıma modeli ve ticari deneme hakları korunur.
