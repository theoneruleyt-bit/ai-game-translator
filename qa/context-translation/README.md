# Translation evidence — 0.29 opt-in beta

These are engineering probes, not a certification of translation quality.

- 30 English/Turkish game-like reference pairs were authored before the new model runs. Source text is typed, so this does not measure ASR.
- `general-prompt.json`: Tiny OPUS-MT chrF++ 66.055; larger OPUS-MT 66.153; Hy-MT2 66.344. The numerical difference does not establish a meaningful overall improvement. No ML Kit comparison was performed.
- `domain-prompt.json`: adding “video-game or film” gave Hy-MT2 64.976 on the same references.
- `official-prompt.json`: the source model default prompt gave Hy-MT2 60.017. Different valid Turkish paraphrases can reduce overlap; overlap also does not expose every meaning error.
- The final app uses the general isolated-line prompt and the source model background-information template when previous accepted English sources exist. It never supplies previous Turkish guesses as facts.
- Ten follow-up probes were added after candidate selection. These are exploratory, not held-out evaluation. `long-prompt-followup.json` and `official-followup.json` retain both successful and failed outputs. Do not select only good examples.
- `final-prompt-evaluation.json` is generated by the reproducible script using the final app prompt, CPU2, LiteRT-LM 0.16.1. All requests are fresh single-message native conversations. Host runs may overlap a build and cannot establish Android latency.

## Observed meaning limitations

The general prompt translates “I am not buying it” as “Buna inanmıyorum” and “You are pulling my leg” as “Şaka yapıyorsun”; the Tiny model translated those literally in this set. However, other examples still reverse a pronoun or mishandle a command: “Hold your fire” becomes “Sakin ol” in isolated tests. With rifle context the official template returned “Silahını bırak”, which also changes the command. An earlier long background prompt even contaminated the result with the background sentence. The app uses the simpler upstream context template, but that does not remove all semantic errors.

Therefore the feature ships disabled, clearly labeled beta. It is NOT a proven replacement for the lightweight engine in every case, and NOT verified equivalent to Samsung Interpreter. Do not enable it by default for a public Play release on this evidence.

## Runtime and device limits

The downloaded model is 1,827,026,224 bytes (SHA-256 and immutable revision in `model-pin.json`). The model card and upstream license identify **Hy-MT2**, Apache-2.0. This is not the older territorially restricted HY-MT1.5 license. Model weights are not redistributed in the APK or source ZIP.

The integration checks memory/64-bit support, warms the model before capture/trial accounting, tries GPU then CPU, and has a 4.5-second request deadline. Late work is cancelled/invalidated and cannot append to a later session. An occupied native worker cannot accept another request. The existing ML Kit lane remains available and is visibly labeled on fallback. These are technical safeguards, not quality measurements.

No physical S23 Ultra, other Android phone, sustained heating/battery test, recording with music, or end-to-end camera/microphone/TTS test was available in this environment. Reference hardware results from model publishers are not our phone measurements.

## Reproduce

Install `litert-lm==0.16.1` and `sacrebleu==2.6.0` in a separate host Python environment. Supply the pinned model file, then run:

```
python scripts/evaluate_context_translation.py --model /path/Hy-MT2-1.8B_int8.litertlm --output results.json --threads 2
```

Read the source, reference, raw translation, and full context together. Do not interpret chrF++ as an accuracy percentage.
