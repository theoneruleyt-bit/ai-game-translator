# 0.16.1 — Tanıma süresi test düzeltmesi

0.16 paketinde tanıma süreleri azaltılırken eski RecognitionTuningTest beklentileri güncellenmemişti. Hızlı modun 0.25 yerine 0.20 saniye ve dengeli modun 8 yerine 5 saniye beklemesi gerekir. Test yeni değerlerle güncellendi; tam mod ve tekrar hızlı moda dönüşte seçeneklerin çoğalmadığı, orijinal yapılandırmanın ve beam değerinin korunduğu kontrol ediliyor.

Paylaşılan GitHub kaydında debug/release Kotlin derlemesi, APK/AAB üretimi ve iki lint görevi geçti. 61 testten yalnızca bu test başarısızdı. 0.16.1 Kotlin test sonucu yeni GitHub çalıştırmasında doğrulanmalıdır; yerel Android SDK/Kotlin derleyicisi yoktur.

Uygulamanın dinleme akışı veya yeni dil paketleri değiştirilmedi. VersionCode 21 ve mevcut test imzası korundu.

ZIP içeriğini mevcut proje klasörüne, .github dahil üzerine kopyalayın:

```
git add .
git commit -m "Fix recognition tuning test expectations for v0.16.1"
git push
```

Yeşil olduktan sonra Releases → en yeni Translator CI taslağı → ci-download.zip dosyasından APK alın. Telefon testi için LIVE_SPEECH_0_16.md yönergelerini kullanın.
